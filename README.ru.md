Единый центр управления на rofi: **приложения, буфер обмена, эмодзи, обои и
анимации** — на одной клавише, вместо нескольких отдельных вызовов rofi с
разными темами.

Началось это как лаунчер с папками и закреплёнными, и он никуда не делся: твои
программы по-прежнему сверху, в заданном тобой порядке. Просто под ними теперь
лежит всё остальное.

`drun` показывает сразу все приложения в порядке, который выбрал rofi. Это
удобно, когда знаешь, что ищешь, и неудобно, когда не знаешь. Здесь программы,
которыми ты реально пользуешься, лежат сверху, а остальное убрано в папки.

## Разделы

Нажал клавишу — открылось меню из пяти строк. Нажал цифру — открылся раздел.

| | Раздел | Что делает | На чём |
|---|---|---|---|
| `1` | **Менеджер приложений** | избранное; `Tab` — все приложения | `.desktop` |
| `2` | **Буфер обмена** | история; `Enter` копирует, `Ctrl+X` удаляет | `cliphist` |
| `3` | **Эмодзи** | 556 символов с русскими именами | своя база |
| `4` | **Обои** | сетка превью | свой скрипт, отдельное окно |
| `5` | **Анимации** | 11 пресетов с превью и живым показом | `hyprctl`, `hypr-dissolve` |

Цифры работают **из любого раздела**, а не только из меню: перейти из эмодзи в
буфер — одно нажатие. Плата честная: rofi вешает привязку на всю сессию,
поэтому цифру нельзя набрать в строке фильтра.

## Что внутри

- **Закреплённые в твоём порядке.** `Ctrl+P` закрепляет выделенное,
  `Ctrl+Alt+↑↓` двигает. Закреплённые живут вверху главного экрана.
- **Папки, которые задаёшь ты.** По категории `.desktop`, по имени или «всё» —
  плюс исключения, чтобы вычесть лишнее.
- **Вход в папку не пересоздаёт окно.** rofi остаётся открытым, меняются только
  строки: ни мигания, ни потери фокуса клавиатуры. `Alt+←` — назад.
- **Поиск не в той раскладке.** Набранное без переключения раскладки всё равно
  находит приложение: `ghjdjlybr` находит Thunar. Настраивается и легко
  выключается.
- **Частота там, где она уместна.** «Все приложения» поднимает наверх то, что
  запускаешь чаще; тематическая папка остаётся по алфавиту — чтобы пункт был
  там, где ты его видел в прошлый раз.
- **Честное чтение desktop-файлов.** `NoDisplay`, `Hidden`, `TryExec`,
  `OnlyShowIn`/`NotShowIn` и локализованные имена учитываются, а подстановочные
  поля (`%U`, `%F`, …) никогда не попадают в командную строку.
- **Запуск через `gio`**, поэтому `Path=`, startup notification и активация
  через DBus работают по спецификации. Для терминальных приложений есть
  собственный запасной путь: `gio` отказывается их запускать, если твоего
  терминала нет в списке, зашитом в GLib.

## Требования

- `rofi` 1.7+ (script mode с `use-hot-keys`)
- Python 3.9+
- Для отдельных разделов, каждый необязателен — без него раздел честно скажет,
  чего не хватает: `cliphist` и `wl-clipboard` (буфер, эмодзи), `hyprctl`
  (окна, анимации), `python-pillow` (рисование превью анимаций)
- Nerd Font для глифа папки и звезды закрепления — тема в комплекте просит
  JetBrainsMono Nerd Font
- Опционально: `glib2` (`gio`), настоятельно рекомендуется; без него `Exec`
  разбирается вручную

Root не нужен. Всё живёт в домашнем каталоге.

## Установка

```bash
git clone https://github.com/Whyslab/rofi-launcher.git
cd rofi-launcher
./install.sh
```

Дальше — повесить на клавишу. Hyprland:

```bash
$menu = ~/.local/share/rofi-launcher/bin/hub.sh
bind = SUPER, R, exec, $menu
```

Sway или i3:

```
bindsym $mod+r exec ~/.local/share/rofi-launcher/bin/hub.sh
```

`./install.sh --dry-run` покажет, что будет сделано; `./install.sh --prefix /tmp/t`
поставит во временный каталог.

## Как пользоваться

| Клавиши | Что делает |
|---|---|
| просто печатать | фильтр, в том числе в неправильной раскладке |
| `↑` `↓` | перемещение |
| `Enter` на приложении | запустить и закрыть |
| `Enter` на папке | войти — окно остаётся открытым |
| `Alt+←` | назад на главный экран |
| `Ctrl+P` | закрепить выделенное, а закреплённое — открепить |
| `Ctrl+Alt+↑↓` | двигать закреплённое вверх и вниз |
| `1`…`5` | открыть раздел, откуда угодно |
| `Tab` | в менеджере приложений: избранное ↔ все приложения |
| `Ctrl+X` | удалить запись буфера обмена |
| `Esc` | закрыть |

В сетке анимаций своя пара: `Enter` применяет пресет насовсем,
`Ctrl+Alt+Пробел` показывает его вживую. Не `Ctrl+Пробел` — он занят самим rofi
под `kb-row-select`, и попытка его переопределить заставляет rofi показать
диалог ошибки вместо меню.

### Анимации

Пресет — это один JSON в `data/presets/`, описывающий весь образ движения
сразу: анимации окон, столов и слоёв, свои кривые Безье и параметры плагина
`hypr-dissolve`. Половина пресета — не внешний вид.

Применить и посмотреть — разные вещи:

| | Живое превью | Применить |
|---|---|---|
| Механизм | `hyprctl keyword` | генерируется конфиг + `hyprctl reload` |
| Пишет файлы | нет | да |
| Откат | `hyprctl reload` | выбрать другой пресет |

Превью поэтому не может испортить настройки: оно ничего не записывает, а
`reload` — настоящая кнопка отмены.

Что есть в комплекте:

| С распадом | Без распада |
|---|---|
| **Распад** — как было по умолчанию | **Сдвиг** — уезжает вбок, быстро |
| **Пыль** — мелко и широко разлетается | **Масштаб** — растёт из центра |
| **Туман** — оседает и долго висит | **Пузырь** — выскакивает с перелётом |
| **Взрыв** — крупные осколки, резко | **Плавно** — только проявление, ничего не двигается |
| | **Вертикаль** — всё ездит сверху вниз |
| | **Кино** — медленно и с оттяжкой |
| | **Без анимаций** — всё выключено |

Генерируются **оба** формата конфига Hyprland, классический и Lua. Как только
рядом появляется `hyprland.lua`, композитор перестаёт читать `.conf` целиком —
а висящий `dofile` на несуществующий файл роняет его в аварийный режим.

### Как задать папки

`~/.config/rofi-launcher/folders.conf`. Порядок секций — порядок на экране:

```ini
[Development]
@category: Development
-some-tool.desktop          # вся категория, кроме этого

[Internet]
@category: Network
@category: WebBrowser

[Каждый день]
@icon: applications-utilities
firefox.desktop             # поимённо, в том порядке, как написано
thunar.desktop

[All applications]
@all
```

| Директива | Что значит |
|---|---|
| `@all` | все найденные приложения |
| `@category: X` | всё, у чего в `.desktop` объявлена категория X |
| `name.desktop` | конкретный пункт, в порядке написания |
| `-name.desktop` | исключить, откуда бы он ни пришёл |
| `@icon: имя` | иконка папки |

Поимённые строки и `@category` можно смешивать; пункт не появится дважды.
Исключения действуют независимо от того, где в секции они написаны.

### Закреплённые

`~/.config/rofi-launcher/favorites.list` — по одному `.desktop`-идентификатору
в строке, в порядке отображения. Файл перезаписывается при каждом `Ctrl+P` или
перестановке, поэтому комментарии ниже шапки не сохраняются: он задуман как
управляемый из лаунчера, а не редактируемый руками.

### Поиск не в той раскладке

Две раскладки хранятся строками одних и тех же клавиш в одном порядке, поэтому
набранное в другой можно перевести обратно. По умолчанию — QWERTY и ЙЦУКЕН.
Другая пара:

```bash
export ROFI_LAUNCHER_LAYOUT_PRIMARY="qwerty…"
export ROFI_LAUNCHER_LAYOUT_SECONDARY="ασδφγη…"   # те же клавиши, тот же порядок
```

Пустая строка в любой из двух выключает поведение. Если длины разные, функция
отключает себя сама, а не переводит наугад.

### Остальные настройки

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `ROFI_LAUNCHER_TERMINAL` | `kitty` | терминал для `Terminal=true` |
| `ROFI_LAUNCHER_THEME` | встроенная `hub.rasi` | `.rasi` для списка; пусто — твой конфиг rofi |
| `ROFI_LAUNCHER_GRID_THEME` | встроенная `grid.rasi` | `.rasi` для сетки анимаций |
| `ROFI_LAUNCHER_DEBUG` | не задано | писать каждый вызов в `~/.cache/rofi-launcher/debug.log` |

## Как это устроено

Script mode в rofi — это разговор через stdout и переменные окружения
(`man rofi-script`). Скрипт печатает строки; rofi их показывает и вызывает
скрипт снова, сообщая, что произошло. Состояние между вызовами — одна строка,
которую скрипт передаёт сам себе:

```
ROFI_RETV=0                → первый вызов, печатаем главный экран
ROFI_RETV=1, ROFI_INFO=…   → выбрана строка: запустить или войти в папку
ROFI_RETV=10..28           → Ctrl+P и прочие (нужен use-hot-keys)
ROFI_DATA=…                → в какой мы папке; задано прошлым вызовом
```

Поэтому вход в папку и не пересоздаёт окно: ничего не перезапускается, тот же
экземпляр rofi просто получает новый список.

Отладка вообще без rofi:

```bash
ROFI_RETV=0 ./rofi_hub/hub.py | cat -v          # что получил бы rofi
ROFI_DATA=emoji ROFI_RETV=0 ./rofi_hub/hub.py   # сразу нужный раздел
./rofi_hub/hub.py --dump-apps                   # все найденные пункты
```

Обои и анимации — единственные, кто открывается **своим** окном rofi. Им нужна
сетка с крупными превью, а rofi не умеет менять раскладку по ходу сессии: его
директива `theme` документирована как пригодная только для мелочей вроде цвета
фона виджета. Хаб перед этим закрывается — две поверхности layer-shell дерутся
за клавиатуру, и вторая молча не принимает ввод.

Привязки клавиш живут в `bin/hub.sh`, а не в `~/.config/rofi/config.rasi`, и это
намеренно: глобальное переопределение `Ctrl+P` сломало бы его во всех остальных
меню rofi на машине.

> **Грабли, о которых стоит знать:** rofi резолвит привязку по *символу*, а не по
> физической клавише, поэтому `Ctrl+P` в кириллической раскладке — это совсем
> другая привязка (`Control+Cyrillic_ze`). Перечислять нужно все варианты через
> запятую, иначе клавиша молча не работает в половине случаев. Именно этим и
> является список в `bin/hub.sh`.

## Чего это не умеет

- **Превью анимаций не анимируются.** Rofi собран только с
  `gdk_pixbuf_new_from_file_at_scale` — загрузчиком одного кадра; функции
  `gdk_pixbuf_animation_new_from_file` в бинарнике нет вообще. Гифка
  отрисовалась бы первым кадром, то есть чаще всего пустым прямоугольником.
  Вместо этого каждый тайл рисуется из чисел самого пресета и показывает след
  движения; посмотреть по-настоящему — `Ctrl+Alt+Пробел`.
- **Списки не обновляются, пока окно открыто.** Script mode вызывает скрипт
  только на выбор или хоткей, так что окна и буфер читаются при входе в раздел.
- **Цифру нельзя набрать в фильтре.** `1`…`5` отданы под открытие разделов, а
  rofi вешает привязку на всю сессию, не на один экран.
- **Пара раскладок ровно одна.** Две, не три.
- **Иконки — текстовые глифы, а не картинки.** Script mode в rofi умеет иконку
  на строку, но каждая стоит поиска в теме иконок; здесь оставлены глифы, чтобы
  меню открывалось мгновенно.
- **`Ctrl+Shift+P` не привязан** намеренно: в кириллической раскладке он не
  срабатывал даже со всеми четырьмя вариантами keysym. Вместо него переключает
  `Ctrl+P`. Обработчик на месте, если захочешь повесить другую клавишу.
- **Действия из `.desktop` не показаны.** «Новое окно», «Приватное окно» и
  прочие подпункты игнорируются; запускается только основной пункт.
- **Счётчик запусков не устаревает.** То, чем ты активно пользовался год назад,
  держит своё место в «Все приложения».

## Удаление

```bash
./uninstall.sh              # снести программу, папки и закреплённые оставить
./uninstall.sh --purge      # снести и их
```

Привязка клавиши не трогается — убери строку `SUPER+R` сам или верни её на
`rofi -show drun`.

## Разработка

```bash
pip install pytest ruff
pytest tests/ -q
ruff check .
```

36 тестов: разбор desktop-файлов (все способы спецификации сказать «не
показывать» и все подстановочные поля, которым нельзя попасть в argv), сборка и
порядок папок, перевод раскладки и сам протокол rofi — что перевод строки или
служебный байт внутри имени приложения не может сдвинуть строки, которые
разбирает rofi.
